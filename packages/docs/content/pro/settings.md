Settings live in the account panel. Open it from your address in the top bar.

## Appearance {#appearance}

Pick Light, Dark or System, then a preset for each. Changes apply as you tap, with no save button.

| Mode  | Presets                                              |
| ----- | ---------------------------------------------------- |
| Light | Paper, Linen, Concrete, Porcelain with high contrast |
| Dark  | Graphite, Walnut, Slate, Onyx for OLED screens       |

Appearance is saved in this browser and shared with Matchscan, Matchbox ID and these docs. It is not saved to your account yet.

## Haptics {#haptics}

On phones, Pro gives a short vibration as feedback on some actions. Turn it off with the Haptics switch.

## Network {#network}

Matchbox reads through Matchbox and writes through your wallet. Custom RPC sends every read and simulation to an endpoint you choose.

Press Test before Save: it shows the chain, the latest block and how long the endpoint took. The setting is stored in this browser only.

## Signing {#signing}

Wallet signs each step in your wallet. Multisig sends each action to a Safe, as [Multisig](/pro/multisig) explains.
