An address page gathers what a wallet holds and did on Mezo. Labelled addresses show their name, and contracts are marked as such.

## Tabs {#tabs}

| Tab              | What it shows                                         |
| ---------------- | ----------------------------------------------------- |
| Positions        | Loans, Enclave positions and locks, with their health |
| Votes            | The address's votes by epoch                          |
| Activity         | What it did, in plain words                           |
| Loan history     | Trove, Morpho and Enclave events                      |
| Transfers        | Token transfers                                       |
| All transactions | Every transaction, with a pager                       |

Each tab has its own address, such as `/address/0x…/votes`, so it can be shared.

## Open in Pro {#open-in-pro}

Open in Matchbox Pro shows the same address in Pro, read only. Voting and claiming happen there.
