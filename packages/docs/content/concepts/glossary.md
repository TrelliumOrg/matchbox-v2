Every term the Matchbox products use, in one list. Each links to the page that explains it.

| Term             | Meaning                                                                       |
| ---------------- | ----------------------------------------------------------------------------- |
| Auto max         | A lock setting that keeps full voting power with no unlock date               |
| Ballot           | One lock's split of votes across gauges on one voter                          |
| Boost            | 1× to 5× extra voting power for a veBTC lock, from veMEZO votes               |
| BoostVoter       | The voter for veBTC gauges, voted with veMEZO                                 |
| Claim and relock | A Matchbox flow that claims rewards and adds the MEZO to a veMEZO lock        |
| Enclave          | A custody contract that mints MUSD against veBTC for allowlisted institutions |
| Epoch            | One week, from Thursday 00:00 UTC to the next Thursday                        |
| Gauge            | Something locks vote for, with incentives on it                               |
| Incentives       | Tokens added to a gauge for its voters, split by voting weight                |
| Lock             | A veBTC or veMEZO NFT holding locked tokens until its unlock date             |
| MEZO gauge       | A gauge on the ThirdPartyVoter that sends MEZO to pools on other chains       |
| MUSD             | Mezo's stablecoin                                                             |
| Optimize         | Pro's split that earns the most incentives this epoch at current votes        |
| Poke             | Recomputing a lock's votes or boost, which anyone can do                      |
| Pool gauge       | A gauge on the PoolsVoter for a DEX pool or a vault, voted with veBTC         |
| Reset            | Clearing a lock's votes, needed before a merge or withdraw                    |
| Trove            | An MUSD loan against BTC that must stay above a 110% collateral ratio         |
| Validator gauge  | A gauge on the ValidatorsVoter for a Mezo validator, voted with veBTC         |
| veBTC            | BTC locked for up to 28 days                                                  |
| veBTC gauge      | A gauge on the BoostVoter for one veBTC lock, voted with veMEZO               |
| veMEZO           | MEZO locked for up to 208 weeks                                               |
| Voting power     | A lock's weight in votes, falling to zero at the unlock date                  |
