Copy, exactly

Lockup MATCHBOX CLASSIC. Line "The original Matchbox app", no full stop. Link "Open Classic" with the external arrow, to https://app.matchbox.markets, same tab.

Rebuilt, not a screenshot

HTML and CSS from apps/webapp: IBM Plex Mono, Header nav labels in their own case (dashboard, veMEZO, veBTC, pools, MEZO gauges, more), the orange > and 2px #F7931A underline on the active item, the signed-out dashboard heading $ dashboard --status.

Classic's own colours

Light: ground #FAFAF9, surface #FFFFFF, border #E7E5E4, text #1C1917 and #57534E. Dark: #0C0C0C, #161616, #2A2A2A, #FAFAF9, #A8A29E. It follows the page theme.

Behaviour

The rendition is decoration: aria-hidden, not focusable, no hover. Only "Open Classic" is a link. Cropped at the card's bottom edge on purpose. Phone shows four menu items and no wordmark.
